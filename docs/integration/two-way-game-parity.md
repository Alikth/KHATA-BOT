# معماری مستقل ربات KHATA-GAMES

این سند جایگزین طرح قدیمی اتصال دوطرفه است. ربات و سایت دو محصول مستقل‌اند و هیچ ارتباط شبکه‌ای یا تبادل داده‌ای ندارند. همه قابلیت‌های بازی در ربات باید با PostgreSQL خود ربات اجرا شوند. مواردی مانند تاریخچه مشترک، sync، reconciliation بین D1 و PostgreSQL، event cursor و تست ارتباط بین دو دیتابیس خارج از محدوده‌اند.

## الزامات
- هیچ API client، webhook، event consumer یا HTTP call به سایت.
- انتساب لرد فقط با `set lord` توسط `BOT_OWNER_ID` و ثبت در PostgreSQL.
- تجارت، جنگ، اتحاد، سناریو، انتقال نیرو و مدیریت دارایی‌ها کاملاً محلی.
- تراکنش، قفل ردیف، قیود دیتابیس و کلید idempotency برای جلوگیری از عملیات هم‌زمان و تکراری.
- تاریخچه تجارت/نبرد و گزارش اختلاف فقط در خود ربات.
- هر تغییری در سایت خارج از این پروژه است.
